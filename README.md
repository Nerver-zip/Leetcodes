## What is inside

Every archived problem has its own directory under [`Solutions/`](./Solutions/):

```text
Solutions/
├── easy/
├── medium/
└── hard/
    └── <problem-id>-<problem-slug>/
        ├── solution.<language>
        ├── README.md
        └── metadata.json
```

Each entry includes:

- the accepted source code and language;
- the problem statement and direct LeetCode link;
- runtime and memory measured by LeetCode;
- an estimated time and space complexity summary;
- structured metadata for tooling and future analysis.
